# MiroFishを用いた投資シミュレーションエンジン開発 調査・設計メモ

作成日: 2026-05-11

## 0. 前提と結論

本ドキュメントは、MiroFishを活用して株・FX・BTC/暗号資産などの価格データを扱う投資シミュレーションエンジンを開発できるかを、実装前に調査・整理したものです。

結論として、初期開発では **BTCのバックテストまたはペーパートレードを最小スコープにする** のが最も現実的です。ただし、MiroFishは現時点では価格系列を直接処理する定量バックテストエンジンではなく、文書・シナリオ・ニュース・市場材料をもとにマルチエージェントで反応やシナリオを推定する「社会シミュレーション寄り」のエンジンです。そのため、MiroFishを売買判断の中核に置くのではなく、以下のような補助レイヤーとして扱う設計が適しています。

- 価格データ、テクニカル指標、売買ルールは通常の定量バックテスト基盤で処理する
- MiroFishには「市場材料」「ニュース」「オンチェーン・センチメント要約」「直近の価格変動説明」などを入力し、補助的なシナリオ評価やリスクコメントを生成させる
- 売買判断ログには、定量シグナルとMiroFish由来の補助判断を分けて保存する
- 実売買は当面行わず、バックテスト、ペーパートレード、手動承認付き売買の順で段階的に検証する

重要: 本システムは投資助言、利益保証、自動的な収益獲得を目的とするものではなく、検証・学習・研究用のシミュレーション基盤として設計する必要があります。

## 1. MiroFishの実態調査

### 1.1 概要

MiroFishは、`666ghj/MiroFish` として公開されているオープンソースのマルチエージェント型シミュレーションエンジンです。GitHub上の説明では、現実世界の種情報、たとえばニュース、政策案、金融シグナルなどを抽出し、エージェント、記憶、関係性、行動ロジックを持つ「平行デジタル世界」を構築してシミュレーションするものとされています。

公式README上では以下のワークフローが示されています。

- Graph Building: 種情報の抽出、記憶注入、GraphRAG構築
- Environment Setup: エンティティ関係抽出、ペルソナ生成、エージェント設定
- Simulation: Twitter/Reddit風の二重プラットフォーム並列シミュレーション
- Report Generation: シミュレーション後のレポート生成
- Deep Interaction: エージェントやReportAgentとの対話

技術構成は、公式リポジトリ上ではPythonバックエンド、Vueフロントエンド、Node.js 18+、Python 3.11-3.12、uv、Docker構成が示されています。ライセンスはAGPL-3.0です。

参照:

- [666ghj/MiroFish GitHub](https://github.com/666ghj/MiroFish)
- [amadad/mirofish-cli GitHub](https://github.com/amadad/mirofish-cli)

### 1.2 主要機能

確認できる主要機能は以下です。

| 項目 | 内容 |
|---|---|
| 入力 | PDF、Markdown、テキスト、自然言語の予測要件 |
| 前処理 | エンティティ抽出、関係抽出、知識グラフ構築 |
| シミュレーション | エージェントペルソナ生成、Twitter/Reddit風の投稿・返信・反応 |
| 出力 | 予測レポート、構造化JSON、タイムライン、エージェント情報、ログ |
| 実行形態 | 公式版はWeb UI + Backend API構成、派生版にCLI-only実装あり |
| LLM依存 | LLM APIキーまたはCLIプロバイダに依存 |
| ライセンス | AGPL-3.0 |

CLI派生版 `mirofish-cli` では、`mirofish run --files ... --requirement ... --json` のような実行形式が示され、実行成果物として `manifest.json`、`ontology.json`、`graph.json`、`timeline.json`、`actions.jsonl`、`verdict.json`、`summary.json`、`report.md` などが出力されるとされています。

### 1.3 入出力形式

MiroFish本体・派生CLIの公開情報から推定できる入出力は以下です。

入力:

- PDF、Markdown、TXTなどの資料ファイル
- 自然言語のシミュレーション要件
- 環境変数によるLLM API設定
- 公式Web版ではアップロードとWeb UI入力

出力:

- 人間向けのMarkdownレポート
- 機械可読なJSON
- エージェント行動ログ
- タイムライン
- シミュレーション設定
- SVGなどの可視化成果物

投資シミュレーションに使う場合は、OHLCVの時系列データをそのまま大量投入するより、価格変動、指標、ニュース、相場局面、リスクイベントを要約した資料をMiroFishへ渡し、構造化された補助判断を受け取る形が現実的です。

### 1.4 APIまたはCLIとして利用できるか

公式MiroFishはフロントエンドとバックエンドを持つWebアプリ構成で、ローカルではFrontend `http://localhost:3000`、Backend API `http://localhost:5001` として起動する説明があります。一方で、直接的な安定公開API仕様は、投資シミュレーション基盤に組み込むには追加調査が必要です。

CLI用途では、英語化された派生版 `amadad/mirofish-cli` が存在し、CLIでの実行、JSON出力、成果物エクスポートがREADMEに明記されています。投資シミュレーションエンジンとの結合では、まずCLI派生版をPoC対象にした方が制御しやすい可能性があります。

ただし、派生版は公式本体ではないため、以下のリスクがあります。

- API互換性が公式と一致しない
- メンテナンス継続性が不確実
- CLIプロバイダ、LLM実行環境、成果物スキーマが変わる可能性
- AGPL-3.0のライセンス義務を設計段階で確認する必要

### 1.5 金融データとの連携可否

MiroFish単体には、OHLCV取得、注文管理、約定シミュレーション、手数料・スリッページ計算、ポートフォリオ評価などの金融バックテスト機能は確認できません。

ただし、金融データとの「間接連携」は可能です。

- 価格データを別レイヤーで取得する
- 指標とイベントを要約する
- 要約をMiroFishに入力する
- MiroFishの出力を補助判断・説明・リスクコメントとして保存する
